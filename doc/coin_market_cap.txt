https://coinmarketcap.com/ service предоставляет HTTP API.
Можно получить текущие цены для указанных крипто валют.
Цены кешируются/меняются каждые 60 секунд.

Нужно зарегаться на их сайте под Basic subscription.
И взять API_KEY, который передавать в HTTP header'e.

# Returns a lightweight latest price for one or more cryptocurrencies
curl -X GET \
  --header 'X-CMC_PRO_API_KEY: '"${COIN_MARKET_CAP_API_KEY}" \
  'https://pro-api.coinmarketcap.com/v2/simple/price?symbol=BTC,ETH,trash,USDT&convert=USD'
